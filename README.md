# 라이브 추첨 (Live Draw)

X(트위터) 라이브 코멘트 캡쳐 → 닉네임 추출 → 랜덤 추첨 → 아이템 룰렛 → 결과 화면.

## 실행

```bash
python3 -m http.server 5173
# 브라우저에서 http://localhost:5173
```

## 흐름

1. **캡쳐 업로드** — 드래그/클릭/⌘V 붙여넣기 (여러 장 가능). "닉네임 추출"을 누르면 OCR(Tesseract.js, 한국어+영어)로 `@핸들`을 자동 추출하고 중복은 제거합니다. 놓친 이름은 직접 입력하거나 "인식된 전체 텍스트 줄"에서 골라 추가합니다.
2. **추첨 · 룰렛 (3분할)** — 참가자 목록 | 몇 명 뽑을지 입력 후 슬롯 추첨 | 당첨자별로 아이템 룰렛 돌리기.
3. **결과** — 당첨자와 아이템을 한 화면에 표시합니다.

- 난수는 `crypto.getRandomValues` 사용
- 아이템 목록은 브라우저에 저장되어 다음 방송에도 유지됨
- 첫 OCR 실행 시 언어 데이터(수 MB)를 내려받으므로 인터넷이 필요합니다
